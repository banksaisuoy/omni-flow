# omni-flow

![Search Feature](https://img.shields.io/badge/Search-Enabled-success)

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Search Feature
The OmniFlow platform includes a global full-text search feature powered by Lunr. 
The search indexes `.md`, `.json`, `.ts`, `.tsx`, `.js`, and `.jsx` files.

### Usage
- Enter a query into the global search bar at the top of the interface.
- Results update in real-time as you type, rendering formatted code snippets.
